# 三态草图 — vendor-if-doctor（80×24 终端 ASCII）

> 本草图是 `视觉目标卡.md` 中「三态精确到字段」的 ASCII 落地。所有画面**严格约束在
> 终端 80 列 × 24 行**，用普通 ASCII 字符绘制；不使用任何 box-drawing 扩展字符之外的
> Unicode emoji 或符号。三态对应 CLI / Markdown / HTML 三种交付形态。

## 起始态（命令没有跑出来之前）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ $ vendor-if-doctor run --vendor all --config production.yaml                 │
│ [▌▌▌▌▌▌   ] running his.outpatient-register …  (latency 312ms)               │
│                                                                              │
│ (按 vendor 顺序滚动，每行最多显示 1 个 vendor 的进度：)                       │
│   ▌▌▌▌▌     running his.outpatient-register ...      312ms                    │
│   ▌▌▌▌▌▌▌   running lis.test-result-query    ...      187ms                   │
│   ▌▌▌▌▌     running pacs.study-fetch          ...      timeout              │
│   ▌▌▌▌▌▌    running emr.discharge-summary     ...      421ms                  │
│   ▌▌▌▌      running medical-insurance.claim-submit ... 510ms                  │
│   ▌▌▌▌▌▌▌▌  running regional.read-only        ...      198ms                  │
│                                                                              │
│ (底部固定行：当前并发数 + 已用时间)                                          │
│   concurrency: 6/10      elapsed: 00:00:08                                   │
└──────────────────────────────────────────────────────────────────────────────┘
```

**画面元素清单**：
- 标题行：命令字符串（rich `Style(color='#2c3e50')`）
- 进度条：`▌` 实心 + 空格（rich `Progress` 默认 8 格）
- 进度文字：vendor_id.interface_id + latency_ms 数字（粗体）
- 状态：仅显示「running / timeout」两类，**不**显示 healthy/degraded/failed（还没有结果）
- 底部固定行：并发数 + 已用时间（暗色 `#6c757d`）

**不允许出现的元素**：
- ✗ 健康率百分比（还没结果）
- ✗ handover.md / tickets.jsonl / vendor_if_doctor.db 路径（还没产物）
- ✗ evidence_hash / summary（Evidence 还没生成）
- ✗ suggested_actions（工单草稿还没渲染）

**画面元素清单**：

- 分隔线：`================================================================`（#2c3e50）
- 关键数值：
  - `vendor_count` / `healthy` / `degraded` / `failed`：纯数字 + 标签
  - `health_rate: 75.0%`：#1c5d99 大字（终端用粗体 + 加大字号模拟）

- 汇总状态行：`OK`（#28a745 healthy）
- 表格：
  - 表头：`+-----+-----+-----+-----+` ASCII
  - 行：每行 1 个 vendor.interface
  - `status` 列：healthy `#28a745` / degraded `#ffc107` / failed `#dc3545` 上色
  - `first_step` 列：仅 failed 行显示（如 `auth` / `sample`），healthy 行显示 `-`

**画面元素清单**：
- 命令行：`history --vendor all --days 7 --format html --output weekly.html`（#2c3e50）
- 汇总块：systems_reported / total_runs / health_rate / anomalies_today
- 路径：`./out/weekly/2026-10-10/weekly.html  (6.2 KB)`
- 三栏布局（在 HTML 周报里，终端只显示 ASCII 摘要）：
  - `[System Connectivity Rate]`：6 个业务系统（按连通率 asc 排序）+ 柱状条 + 百分比
  - `[7-Day Trend]`：7 个系统各 7 个 ASCII 火花字符 `▁▂▃▄▅▆▇█`
  - `[Anomalies (today)]`：今日失败清单 5 列（vendor.interface / status / first_step / evidence_hash(8) / suggested_actions）

- 100% = `██████████`

- 半胜日：`#ffc107`（黄）
